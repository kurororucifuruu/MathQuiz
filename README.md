# MathQuiz 📱

A simple Android math quiz application built with Java. MathQuiz helps users practice basic arithmetic through randomized multiple-choice questions in a clean, dark-themed interface.

## ✨ Features

* 🔢 Randomized arithmetic questions
* ➕ Addition and subtraction
* ✖️ Multiplication and division
* 🎯 Four multiple-choice answers per question
* 📊 Automatic scoring and instant feedback
* 🏆 Final score summary
* 🔄 Replay functionality
* 📱 Simple, mobile-friendly interface
* 🌐 No account or internet connection required during gameplay

## 🛠️ Built With

* **Language:** Java
* **Platform:** Android
* **Build System:** Gradle
* **IDE:** Android Studio

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and download the required dependencies.
4. Run the application on an Android emulator or a connected Android device.

## 🎮 How to Play

1. Open MathQuiz.
2. Tap **Mulai Kuis** to begin.
3. Solve 10 randomized arithmetic questions.
4. Select one of the four answer choices.
5. View your final score and play again.

## 🎯 Project Goal

This project is a learning exercise focused on Android application development, Java fundamentals, UI design, and basic quiz logic.
