# MathQuiz Android

Aplikasi kuis matematika sederhana berbasis Android (Java), tanpa login, database, atau internet.

## Fitur
- 10 soal acak: tambah, kurang, kali, bagi
- 4 pilihan jawaban
- Skor otomatis dan hasil akhir
- Main lagi
- Tampilan gelap yang ramah untuk HP

## Cara membuka dan membuat APK
1. Ekstrak ZIP ini.
2. Buka Android Studio, pilih **Open**, lalu pilih folder `MathQuiz-Android`.
3. Tunggu Gradle sync selesai. Pastikan Android SDK Platform 35 terpasang.
4. Jalankan di emulator/HP, atau pilih **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. APK debug biasanya berada di `app/build/outputs/apk/debug/app-debug.apk`.

## Catatan
Proyek ini berisi source code Android Studio, bukan APK yang sudah dikompilasi. Kompilasi APK perlu Android Studio/Android SDK dan koneksi untuk mengunduh dependensi Gradle saat pertama kali dibuka.
